# WARP.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Repository Purpose

This is a curated "awesome list" of Claude Skills - a collection of links to external repositories, articles, and videos. The repo itself contains no code; it only organizes links to resources.

## Repository Structure

- `README.md` - Main content with categorized skill links, articles, and videos
- `CONTRIBUTING.md` - Contribution guidelines and formatting requirements

## Common Tasks

### Adding a Skill
Add to the appropriate category section in `README.md`:
```markdown
- **[author/skill-name](https://github.com/author/repo)** - Short description
```

### Adding an Article/Video
Add to the Articles and Tutorials section with the appropriate format from `CONTRIBUTING.md`.

## Contribution Standards

From `CONTRIBUTING.md`:
- Skills require: public repo, working skill, documentation, author prefix
- Articles require: public access (no paywall), accuracy
- PR titles follow format: `Add skill: author/skill-name`, `Add article: Title`, etc.

## No Build/Test Commands

This is a documentation-only repository. There are no build, lint, or test commands.
